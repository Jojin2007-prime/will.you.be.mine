# Valentine's Proposal Website 💕 🥋

A romantic, interactive web experience featuring a "Karate Kid" themed intro, custom animations, and a playful "No" button that runs away.

## 🚀 Project Overview
This project was designed to be a unique and fun way to ask someone to be your Valentine. It features a multi-stage flow:
1.  **The Intro:** A Karate Kid themed greeting that unlocks the music.
2.  **The Proposal:** An interactive page with a "No" button that guilt-trips the user and eventually runs away from the cursor.
3.  **The Celebration:** A final "Yes" page with music and a confetti explosion.

## ✨ Features
* **Romantic UI:** Glassmorphism design with falling cherry blossom petals.
* **Interactive Cursor:** A sparkling heart trail that follows the mouse.
* **Dynamic Buttons:** A "Yes" button that grows every time "No" is clicked.
* **Music Integration:** Background music that stays synced across pages.
* **Confetti:** High-energy celebration using the `canvas-confetti` library.

## 🛠️ Built With
* **HTML5** - Structure
* **CSS3** - Romantic animations and layout
* **JavaScript** - Interactive logic and music controls
* **GitHub Pages** - Hosting
